# Examples

Copy-paste starting points for common setups.

| File | Setup |
|---|---|
| [`flat.eslint.config.js`](./flat.eslint.config.js) | ESLint 9 flat config, `recommended` |
| [`nestjs.eslint.config.mjs`](./nestjs.eslint.config.mjs) | NestJS — `strict` + `performance` |
| [`express.eslint.config.js`](./express.eslint.config.js) | Express / plain Node — `recommended` |
| [`multitenant.eslint.config.mjs`](./multitenant.eslint.config.mjs) | Multi-tenant app with custom `tenantKeys` |
| [`.oxlintrc.json`](./.oxlintrc.json) | oxlint (JS-plugin API) |

All rule names are identical across ESLint and oxlint (`typeorm-enterprise/...`).
